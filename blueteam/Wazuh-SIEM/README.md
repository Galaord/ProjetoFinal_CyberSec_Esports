# Wazuh SIEM — Blue Team

Implementação e configuração do Wazuh SIEM
para monitorização, deteção e análise de
eventos de segurança.

## Componentes
- Wazuh Manager, Indexer e Dashboard
- Regras personalizadas de deteção
- Monitorização de eventos SSH e Syslog
- Recolha e análise de alertas
- Evidências de testes de segurança
